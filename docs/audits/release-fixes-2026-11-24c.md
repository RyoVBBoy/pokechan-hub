## 公開の判断

**公開しない（main に入れない）**。理由：指示の第15節の条件1「確かめられた直すべき点がすべて直っている」と条件5「目立つ遅さの悪化がない」を満たしていない。

- 第11節（ダブルの相方を見た評価）・第10節（天気・フィールドの場の状態）は作っていない。第10節は 2026/11/10 の依頼主の判断（パーティの天気を入れる）と食い違うので、依頼主の判断が要る。
- 第12節（346の姿の文の全部の点検など）・第6節（215の特性すべての点検）・第7節（85の持ち物すべて）は一部だけ。
- 改善案が CPU 4倍遅くで約7秒（前は約5.5秒）。
- 本番のサイトでの確かめ（第15節）はしていない（公開していないため）。

## 止まっていること・決めてもらうこと（このブランチでは作っていない）

1. **ダブルの相方を見た評価**（範囲技の相手の数・味方へのダメージ・フレンドガード・このゆびとまれ・てだすけ・ドラゴンアロー等）：作っていない。画面は前から「ダブルは暫定評価」と出している。
2. **天気・フィールド**：パーティに天気を作る匹がいれば、得をする匹の対面で天気を入れる作り（2026/11/10 依頼主の判断）のまま。今回の指示「作る匹がいるだけで天気があるとしない」と食い違うので、依頼主の判断が要る。フィールド（エレキ・グラス・サイコ・ミスト）・じゅうりょく等は計算に入れていない（計算に入っていない特性として知らせる）。
3. 今回の指示で挙がったほかの持ち物（メトロノーム・フォーカスレンズ・シード・せんせいのツメ・おうじゃのしるし等）は「計算に入っていない」と知らせるだけ。かいがらのすず・おおきなねっこ・たべのこし・いのちのたまの反動は、診断の回数に入れていない（前と同じ、前提に書く）。
4. カウンター・ミラーコート・メタルバースト・ほうふく・ふくろだたき・はきだす・なげつける：入力（前のターンの出来事・持ち物）が無いので計算しない。覚えない技としては扱わない（登録はそのまま、「計算に入っていない攻撃技」と出す）。
5. 図鑑の346の姿の文の全部の点検・ランキングの数え方（種類か姿か）などの第12節の残り。
6. チャンピオンズの実機での確かめ（すべて）。
