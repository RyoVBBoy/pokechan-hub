## 6. データの限りと証拠の種類

画面では次を分けて書く：①公式の確認（M-C の一覧・新しい6つのメガ）②上位パーティ：確認済み／本人の申告／記事から集めた ③Showdown の集計（PokéKit）④当サイトが組んだ理論上の型。

- 勝率・順位・使用率は作らない。上位パーティの順位は登録・記事の値をそのまま出し、申告は「（申告）」と書く。
- 仲間の割合は「6匹のパーティではない」「強さの証拠ではない」と書く。
- 能力ポイントは集計に無いので仮定（攻撃側32・素早さ32・HP2）。「EV」という言葉は使っていない。
- ダブルは1対1の計算だけ（ねこだまし・おいかぜ・まもる・範囲技・このゆびとまれ・味方との組み合わせは評価していない）と画面に書く。
