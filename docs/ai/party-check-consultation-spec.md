# パーティチェックからのAI相談

2026-11-27 JST。先行導入はパーティチェック1か所。AI専用ブランチのStage Bを共通基盤として使う。独立チャットを導入の前提にしない。ダメージ計算と選出アシストへのボタン追加は次段階。

## 画面と操作

- パーティ画面の「ダメージ計算」と同じ行に、専用ロゴと「AIに相談」を表示する。リンクを開くとチェックタブが選ばれ、相談の入口に「ベータ版」と表示する。登録が2匹未満なら、その場から追加できる。
- チェック結果が出たら相談パネルを開ける。パネルには対象パーティ、対戦形式、診断の前提、質問例、入力欄、残り回数を表示する。パネルを開くだけでは質問を送信しない。
- 最初の相談に対し、強みとその根拠、次の練習で試すことを1つ表示する。根拠は元の診断の要約・対応する結果にリンクまたは復帰できる形にする。入れ替え案・数値は再計算済みの候補に限る。確かめられない場合は前提を示し、断定を保留する。パーティの保存・差し替えは利用者が既存画面から行う。

## 相談に渡すデータ

- 結果を開いた時点のスナップショットをメモリに固定。ゲーム、形式、ポケモンとフォルムID、必要な育成項目、診断結果の識別子・前提・版を許可リストで抽出する。元HTML・アカウント名・パーティ名・個人メモ・対戦相手の私的な情報は渡さない。実サービスに送る対象は送信前に確認できるようにする。
- クライアント由来の結果は「この端末で計算した結果」。サーバーで再計算か照合ができた場合だけ、その旨を表示する。AIは既存の診断・計算・出典の範囲で説明する。集計なしの診断を使用率上位の集計として表現しない。
- パーティ、育成、形式、対象版または集計条件が変わったら、次の送信前に「結果が更新されました」と示し、新しい結果で相談を始める。続きの相談では、残したいポケモンなどの条件を同一スナップショットに限って引き継ぐ。画面を閉じても試合状態のサーバー側判定を解除しない。ログアウト・退会・アカウント切替で会話と下書き、表示待ちの応答を消す。

## 動作・公開条件

- 既存のAI認証・無料枠（1日5回答・月30回答）・回答カード・停止設定を再利用。パネルを開く、確認に答える、制限・保留・失敗だけでは無料回答枠を使わない。
- [フェアプレイ仕様](./stage-b-fair-play-spec.md) をサーバー側で適用する。入口のツール名や「練習」との自己申告で制限を解除しない。進行中の個別判断では構築・選出・計算を呼ばず、候補や個別指示を出さない。進行中と判定した同じ会話は終了の申告で再開せず、既存の「対戦の振り返り」へのリンクを表示する。対戦状況が不明で回答が変わる場合は確認する。
- PC・スマホでボタンの位置、パネルの開閉とフォーカス復帰、キーボード表示時に質問欄と回答末尾が見えることを試験する。無効設定、未ログイン、既存診断の未完了、結果変更、別アカウントへの遅延応答、送信重複、上限、フェアプレイ制限も検証。正しい対象と診断根拠で「この6匹で次に試すこと」が1つ決まることを完成条件とする。
- 先に本番へ反映し、一般公開前に監査する。公開前は `ai.auditHold` を有効にし、公開画面と配信用 Worker のAIルートを停止する。実API利用・課金・一般公開は別途承認。

## ベータ版で提供する範囲

- `config/public.json` の `ai.partyConsult` でパーティチェックの入口を個別に有効化する。既定は無効。Worker では `AI_ENABLED=1` と `AI_B1_ENABLED=1` の両方が必要。
- パーティの強み・戦い方・次の練習を扱う。チェック結果から対応の目安と練習の相手を1例選び、結果へ戻れるようにする。対象外なら案内を返し、回答枠は消費しない。初期版は高度な入れ替え提案やターン別の指示を扱わない。
- 質問送信時に Worker に渡す診断要約は、メンバーのポケモンID、対戦形式、計算に使った集計の状態、相手の数、安定判定の数、練習例の相手IDと対応できる味方のID。生成AI提供元には質問の読み取りを依頼し、診断要約を渡さない。
- 無料枠は1日5回答、月30回答で共通。日本時間の更新時刻と回数制限の理由を表示する。
- 広告は日次の無料枠を使い切り、月の残り枠がある場合の任意表示を検証する。ベータ実装の広告はブラウザテスト専用で、広告通信と追加枠は発生しない。実配信で追加枠を付ける場合は配信事業者の確認結果をサーバーで検証し、同じ視聴での二重付与を防ぎ、既存の月の上限と費用上限を適用する。対戦中の制限は引き続き適用する。

- 本番ブランチの計算器との統合で、C013の確定数は8回、C015は計算上限8回で確定なし。C050は新しい計算器が扱う「じゅくせい」がAIの対応範囲外。2件の確定数は画面比較でも検証する。
